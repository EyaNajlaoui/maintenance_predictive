# PrognosIA — Predictive Maintenance for Turbofan Engines

Web app for engine health classification (healthy / critical) and Remaining Useful Life (RUL) forecasting from sensor data, using XGBoost and LSTM models trained on the NASA C-MAPSS (FD002) dataset.
